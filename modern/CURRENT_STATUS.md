# 当前交付状态

更新日期：2026-10-23。当前现代版仅有 WinUI 3 前端，入口为 `Start-WinUI.cmd`。以下描述当前现代版代码与验收边界。

## 内核库

界面目前仅提供 BzMiner 适配。首次内核列表为空；点击“导入 BzMiner exe”选择官方解压包里的 `bzminer.exe`，复制到程序所在安装目录的 `Kernels` 子目录并自动选中。选择器只显示名称和版本；导入的内核可以删除。配置保存在安装目录根部的 `profile.json`，内核运行配置与临时算法配置保存在 `Runtime` 子目录。

导入只复制文件，不运行 exe，不读取算法，不自动开挖。除 exe 外，会复制同目录 DLL、许可证，以及 plugins/kernels/licenses 子目录；不复制根目录矿池配置、日志或启动脚本。请从完整解压包中选择文件，不单独搬出 exe 再导入。原始目录不改动。首次启动会把旧版 LocalAppData 中的配置和已导入内核复制到安装目录；旧副本会保留，但之后软件只读写安装目录。旧配置中的外部内核路径需要手动重新导入；历史 SRBMiner 后台代码仍保留兼容测试，但不再出现在当前界面中。

BzMiner 的 `pearlhash` 与 `pearl` 合并显示为一个 `pearl`，保存旧别名时执行参数也统一为 `pearl`。

## 本轮接入

- 配置页可填写算法名，留空保留 PRL 默认值：BzMiner `pearl`、SRBMiner `pearlhash`。点击读取按钮可从所选 BzMiner 读取算法目录，按设备过滤，再选择算法。读取有输出大小与时间限制，使用独立配置并关闭自动更新、Web 和 UDP。
- 矿池模式仍仅支持 PRL 地址和算法；其他算法仅可用于 BzMiner 离线自测，不宣称已经完成多币种联调。
- 可添加、去重、选择和移除已保存 PRL 收款地址。移除当前地址会清空收款字段，不会悄悄切换其他地址；下次启动前需自行选择。只保存公开收款地址，不输入私钥或助记词。
- 备用矿池每行一个，保留用户顺序。BzMiner 重复 `-p`；SRBMiner 使用逗号列表，钱包、矿机名和每个矿池的 TLS 状态保持对应。生成参数已验证，实际网络切换仍需矿池联调。
- 配置 v1–v4 读取后升级到 v5，读取不改原文件；载入失败时关闭自动保存，保护未知版本配置。自动保存串行写入，关闭窗口前等待保存完成。
- 显卡传感器通过后台读取，展示温度、风扇、功耗等可用项；缺失值显示“—”，不当作零。Intel 通用接口常缺温度与功耗，NVIDIA/AMD 接口仍需相应硬件实测。超频保持只读，没有写入硬件功能。
