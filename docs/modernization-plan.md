## 第一阶段范围

- Windows 桌面客户端，目标技术为 .NET 10 LTS 和 WinUI 3（Windows App SDK 2.5.1）。
- PRL 单币种，外部挖矿内核由用户提供；已接入 SRBMiner 与 BzMiner 的参数与日志适配，内核版本、状态接口与授权要求仍以实际发布为准。
- 用户自行选择本地内核文件，初版不打包、下载或再分发第三方内核。
- 钱包、矿池和矿机名配置；启动、停止、日志、算力及份额展示。
- 显式任务状态、有限重试、进程树清理和本地配置迁移。
- 第一个可运行纵向切片以配置校验、进程生命周期和假内核验证为核心，之后再对接真实硬件。

暂缓群控、远程桌面、多币种、自动超频、自动内核下载和自动更新。更新功能在发布前独立实现签名验证及回滚，不沿用旧更新器。

## 模块边界

| 模块 | 职责 |
|---|---|
| Domain | 配置、状态、指标模型和校验规则，不依赖界面或操作系统 |
| Application | 启停及恢复流程、适配器和存储接口 |
| Infrastructure | 进程、存储、Windows 通信和硬件访问 |
| MinerAdapters | 外部内核参数与状态解析；初期采用编译期注册 |
| Agent | 挖矿后台进程，拥有任务状态和子进程 |
| WinUI | 唯一桌面前端，经命名管道调用后台，不直接管理内核进程 |

本机通信使用带访问控制的命名管道。后台进程和界面默认普通权限运行；需要权限的硬件操作后续单独设计。

## 安全约束

- 新版不接入 NoDevFee，不替换钱包，不关闭 Defender、防火墙、UAC 或系统更新。
- 内核必须由用户明确选择并启动，记录路径、版本及文件哈希；本地哈希仅用于识别文件，不能宣称证明来源可信。
- 配置使用结构化字段，避免通过 shell 拼接并执行命令；日志中不记录秘密信息。
- 私钥和助记词不进入客户端配置，挖矿只使用收款地址。
- 不自动导入旧钱包、远程身份或自动启动设置；需要用户核对后迁移。

## 验收标准

1. 配置不完整或字段无效时无法启动，且说明具体原因。
2. 连续启动不会产生多个内核；停止后子进程被清理。
3. 正确区分启动中、运行中、恢复中、停止中和失败状态；进程存活不等于有效挖矿。
4. 临时故障按有限退避恢复，配置错误停止重试并显示原因。
5. 展示内核日志、接受及拒绝份额，实测时与矿池有效算力核对。
6. 先用假内核覆盖启停、异常退出和日志场景；真实硬件验证需单独记录内核版本、驱动和显卡。
